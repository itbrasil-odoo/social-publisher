A content calendar for social media posts. Posts go through drafts, an
approval step and automatic publication at the scheduled time, and the
metrics of every published post are collected daily, with a history per
post and per account.

The module is network-agnostic: networks plug in as separate provider
modules, such as ``social_publisher_linkedin``. It is multi-company and
built on Odoo Community: no Enterprise module is required.

Configuration
=============

To configure this module, you need to:

- Install a provider module, for example *Social Publisher LinkedIn*.
- Go to *Settings > Users & Companies > Users* and give each person a
  *Social Publisher* role:

  - **Writer** creates and edits drafts but cannot approve or publish.
    This is the right role for an assistant or an AI agent that drafts
    posts.
  - **Manager** approves and publishes posts and manages accounts.

- Go to *Social > Configuration > Accounts*, create an account for each
  profile or page and connect it. Leave the company empty to share the
  account with every company.
- Optionally, create tags in *Social > Configuration > Tags* to classify
  posts by topic.
- On each account, *Metrics Window (days)* limits the daily metrics sync
  to recent posts, which keeps the network's daily API limits in check.

Usage
=====

To use this module, you need to:

- Go to *Social > Posts* and create a post: write the text exactly as it
  should appear, pick the account, add tags and, optionally, an image.
- Set *Scheduled For*. A manager clicks **Approve**; approved posts are
  published automatically once that time has passed. **Publish Now**
  skips the wait.
- Editing the text, the image or the account of an approved post sends
  it back to draft, so the approval always matches what goes out.
- If the network refuses a post, it becomes *Failed* with the reason on
  the form, and it is not retried until someone sends it back to draft
  and approves it again.
- Use the calendar to see what goes out when, and drag a post to
  reschedule it. The kanban groups posts by status, and the side panel
  filters them by tag and account.

- Published posts show their metrics on the *Metrics* tab. *Social >
  Metrics* charts the account totals over time.

Known issues / Roadmap
======================

- Only LinkedIn has a provider module so far.
- Posts carry a single image; videos, documents and carousels are not
  supported.
